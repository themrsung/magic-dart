# magic-dart

A typed, rate-limited Node.js client for the [OpenDART](https://opendart.fss.or.kr) API. OpenDART is the Financial Supervisory Service's electronic disclosure system for Korean listed and registered companies (금융감독원 전자공시).

> **Authorship notice:** This codebase was authored by agentic LLM services from US-based providers. A human directed and reviewed the work, but the code, tests and documentation were generated by AI agents. Review it before you rely on it in production.

- Covers all **85 OpenDART APIs** across the six groups: disclosures, periodic report data, financial statements, ownership disclosures, major-event reports and securities registration statements.
- Written in **TypeScript** with **no runtime dependencies**. The published package ships compiled JavaScript with type definitions; in this repo, Node runs the `.ts` sources directly.
- Validates parameters before each request is sent, retries failed requests, and enforces a per-second rate limit and an optional total request budget.
- Includes helpers to normalise raw OpenDART values: large amounts are parsed as `bigint`, and the API's three date formats and filing remark flags are handled.

## Requirements

- Node.js 22.23.4+, 24.22.1+ or 26.12.1+ (the October 2026 security releases; older versions have known vulnerabilities, including in `fetch`, TLS and `node:zlib`)
- An OpenDART API key (`crtfc_key`, 40 characters). The key is IP-locked: OpenDART rejects calls from unregistered IPs with status `012`.

## Install

```sh
npm install magic-dart
```

To work on the repository itself, clone it and run `pnpm install`.

## Usage

```ts
import { OpenDartClient } from 'magic-dart';

const client = new OpenDartClient({
  apiKey: process.env.OPENDART_API_KEY!,
  requestsPerSecond: 10, // default
  maxRequests: 2000,     // optional total budget
});

// Company profile (Samsung Electronics)
const company = await client.company('00126380');

// Filing search, with pages fetched one at a time
for await (const filing of client.searchAll({ corp_code: '00126380', bgn_de: '20250101', end_de: '20250331' })) {
  console.log(filing.rcept_no, filing.report_nm);
}

// Every API is also available by name
const accounts = await client.api.fnlttSinglAcnt({ corp_code: '00126380', bsns_year: 2024, reprt_code: '11011' });

// ZIP-backed endpoints
const corps = await client.corpCodes();             // full corp-code list
const files = await client.document('20250311001085'); // original filing documents
```

Responses keep OpenDART's raw string values. Use the helpers in `src/normalize.ts` (`parseAmount`, `parseNumber`, `parseDate`, `parseRmFlags`, `viewerUrl`) to convert them. Don't call `Number()` on large amounts.

Errors are typed:

- `OpenDartValidationError`: the parameters are invalid. No request is sent.
- `OpenDartError`: OpenDART returned a non-`000` status.
- `OpenDartHttpError`: the request failed at the network or HTTP level.
- `RequestBudgetExceededError`: the `maxRequests` budget is used up.

Status `013` (no data) is returned as an empty result by default. Set `noDataAsEmpty: false` to throw on it instead.

## Scripts

| Command | What it does |
|---|---|
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm build` | Compiles `src/` to `dist/` (JS + `.d.ts`) via `tsconfig.build.json`. Runs automatically before `npm publish` |
| `pnpm test` | Offline unit tests (mocked `fetch`, no network) |
| `pnpm smoke` | Live smoke test that calls every endpoint once. Needs `OPENDART_API_KEY` in `.env` (see `.env.example`) |

## Repository layout

| Path | Contents |
|---|---|
| `src/endpoints.ts` | Registry of all 85 endpoints (path, parameter shape, response shape) |
| `src/client.ts` | `OpenDartClient`: requests, retries, envelope unwrapping, pagination, multi-company chunking, ZIP endpoints |
| `src/params.ts` | Request types and validation |
| `src/rate-limiter.ts` | Per-second rate limit and total request budget |
| `src/normalize.ts` | Amount, date and flag parsing |
| `src/zip.ts` | Minimal ZIP reader built on `node:zlib` |
| `src/types.ts`, `src/errors.ts` | Response row types, status codes and error classes |
| `docs/opendart-api-guide.md` | API reference this client implements |
| `guidelines/` | UI design guidelines for building a frontend on this client |
| `test/`, `scripts/` | Unit tests and the live smoke test |

## Getting an API key

OpenDART lets both individuals and businesses sign up for the API service. You can create an account at `https://opendart.fss.or.kr/`. For business or commercial use, sign up with a Korean business registration number (BRN); business accounts get a higher usage limit. The usage limit figures in this repository's documentation assume you have a working business account.
